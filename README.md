# BioEdu

**BioEdu: 7–9-сынып биология пәнін оқытуға арналған біртұтас цифрлық әдістемелік платформа** (7, 8, 9-сыныптар).

Сайт: https://azamatseitmahambet-ctrl.github.io/bioedu/

Ішінде: 68 сағаттық КТЖ, әр сабаққа ҚМЖ, жұмыс парағы, 3 деңгейлі тапсырмалар, инклюзивті тапсырмалар, виртуалды зертханалар, видеосабақ, рефлексия, қосымша тапсырмалар жинағы.

Оқулық: А.Р. Соловьева, Б.Т. Ибраимова. Биология. 8-сынып. – Алматы: Атамұра, 2018.
